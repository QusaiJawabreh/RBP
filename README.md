# RBP
Code for Robustified Boundary Peeling for Unsupervised Outlier Detection. This is based on BP by Arafat et. al (2025) 

Arafat, S., Sun, N., Weese, M. L., & Martinez, W. G. (2025). Boundary peeling: An outlier detection method. Quality Engineering, 37(4), 583–596. https://doi.org/10.1080/08982112.2025.2469518
